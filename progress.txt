## Verification tool: compare_dry_runs.py
Location: scripts/compare_dry_runs.py

Runs both the old SWE pipeline and cronpypeline in --dry-run --verbose mode
for every enabled repo in the SWE repo registry, then prints a side-by-side
comparison with a unified diff of any discrepancies.

Usage:
    python3 scripts/compare_dry_runs.py              # all enabled repos
    python3 scripts/compare_dry_runs.py --repo cronpypeline  # single repo
    python3 scripts/compare_dry_runs.py --timeout 60         # custom timeout

Key paths it uses:
- Old pipeline: /home/wouter/Repos/spellbook/apps/Serendipity/SWE/scripts/run_swe_pipeline.py
  (run via spellbook's .venv)
- New pipeline: configs/swe_pipeline.json
  (run via cronpypeline's .venv)
- Repo registry: /spellbook_data/Serendipity/swe/repos.json

Exit code 0 = all repos match, 1 = differences found.
